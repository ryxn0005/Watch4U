# preprocessing/

Cleaning and feature-extraction scripts for the public datasets used in Watch4U.

## Suggested files (one per dataset)

- `fallvision.py` — clip filtering, label normalisation (per A2 audit of 11,732 videos)
- `omnifall.py` — cross-dataset alignment with FallVision
- `vimq.py`, `vietmed_ner.py`, `vimedical_disease.py` — VI medical corpora cleanup for RAG

Each script should:

1. Read from `data/raw/<dataset>/`
2. Write to `data/processed/<dataset>/`
3. Log a `manifest.json` describing what it produced (counts, schema, version)

Inputs in `data/raw/` and outputs in `data/processed/` are **git-ignored** — only the scripts themselves are committed. To prevent repository bloat, the `.gitignore` is configured to ignore the `data/raw/` and `data/processed/` folders. You must download the raw datasets to your local machine and run these scripts to generate the processed data locally.

1. Computer Vision Datasets

FallVision

Setup Instructions:

Download the "Raw" video archives (e.g., f_raw_b_1.rar, nf_raw_b_1.rar).

Crucial: Extract the .rar files into folders with their original names. Do not dump all .mp4 files into one giant folder.

Move those folders into data/raw/fallvision/ (e.g., data/raw/fallvision/nf_raw_b_1/B_N_01.mp4). The script reads the parent folder name to determine the "Fall" vs "No Fall" category and generate unique frame IDs.

Run: python fallvision.py

OmniFall

Setup Instructions:

Open your terminal in the data/raw/ directory.

Run: hf download simplexsigil2/omnifall --repo-type dataset --local-dir omnifall

Navigate to data/raw/omnifall/data_files/ and extract the .tar file to unpack the hidden .mp4 videos. The script will recursively find them.

Run: python omnifall.py

YOLO Formatting: The scripts automatically resize frames to 640x640, split data into train/val, and generate the required dataset.yaml.

2. NLP / RAG Dataset
ViMQ (Medical Questions & Intents)
Setup Instructions: Download the train.json, dev.json, and test.json files and place them in data/raw/vimq/.

Action: The script merges all splits, translates custom key names (sent_label), and extracts embedded BIO entities (removing underscores) for precise metadata filtering.

Run: python vimq.py

VietMed-NER (Medical Entities)
Setup Instructions: Download the three .parquet files and place them in data/raw/vietmed/.

Action: The script uses Pandas to parse the .parquet files, decodes the BIO arrays (B-DISEASESYMTOM, I-DISEASESYMTOM), and stitches multi-word symptoms back together alongside their context sentences.

Run: python vietmed_ner.py

ViMedical Disease (Knowledge Base)
Setup Instructions: Download the .csv dictionary file and place it in data/raw/vimedical/.

Action: Forces UTF-8 encoding to prevent Vietnamese mojibake. It splits long encyclopedic paragraphs into digestible sentences and attaches a strict, auditable Vector DB ID (e.g., d14_c2) to every chunk.

Run: python vimedical_disease.py

Final Output
Running all five scripts will fully populate your data/processed/ directory. Each processed dataset folder will also contain a manifest.json logging the schema, version, and output counts.
